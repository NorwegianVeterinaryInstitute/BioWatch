- **Nextstrain (automated real-time phylodynamics)** (Release Date: 2026-03-23) [SURVEILLANCE-READY] #phylogenetics #one-health #surveillance-ready
    - Links: [GitHub org](https://github.com/nextstrain) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.23.713807) | [nextstrain.org/pathogens](https://nextstrain.org/pathogens)
    - Function: Andrews, Neher, Bedford et al. (Fred Hutch / University of Basel) describe Nextstrain's shift to a fully automated, continually-updated real-time genomic surveillance platform covering 21 viruses and *Mycobacterium tuberculosis* — fetching and curating open sequence data, classifying by established nomenclature, running phylogenetic analysis, and publishing results, mostly on a daily cadence with no manual intervention.

- **el_gato** (Release Date: 2026-03-20) #variant-calling #one-health #docker
    - Links: [GitHub](https://github.com/CDCgov/el_gato) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.20.713011)
    - Function: Collins, Willby et al. (US CDC Division of Bacterial Diseases) built el_gato (Epidemiology of Legionella: Genome-bAsed Typing), a WGS-based replacement for Sanger-based sequence-based typing (SBT) of *Legionella pneumophila* that resolves the two known problems blocking a WGS switch — multiple copies of the *mompS* locus and heterogeneity at *neuA*/*neuAh* — from either paired-end short reads or assemblies.
    - Use Case: Brings *L. pneumophila* molecular typing (a water-safety/public-health surveillance task relevant to any lab doing outbreak investigation of waterborne pathogens) onto standard WGS pipelines instead of a parallel Sanger workflow, matching legacy SBT resolution (98.9% concordance vs. Sanger on a 441-isolate validation set, vs. 95.2% and 42.2% for two existing in silico tools).
    - Usability Note: MIT license, README and LICENSE present, 641 commits, 5 stars, installable via Bioconda or Docker, "Maintenance" lifecycle stage declared with named CDC maintainers and a contact email — a solid usability/maintenance signal for a public-health reference tool.

- **OxBreaker** (Release Date: 2026-03-18) #one-health #variant-calling #nextflow
    - Links: [GitHub](https://github.com/oxfordmmm/OxBreaker) (moved to [GitLab](https://gitlab.com/rc-reding/OxBreaker)) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.18.709804)
    - Function: Reding, Walker et al. (University of Oxford) built a species-agnostic Nextflow pipeline for bacterial and plasmid outbreak analysis from Oxford Nanopore reads, with automated reference selection, high-accuracy variant calling, and a GUI aimed at non-specialist infection-prevention-and-control (IPC) teams rather than bioinformaticians.
    - Use Case: Local, offline-compatible real-time genomic surveillance for healthcare-associated-infection outbreaks — matching short-read resolution (0-4 false-positive SNPs against replicates of high-priority pathogens) at nanopore speed, aimed squarely at frontline IPC adoption rather than reference-lab-only use.
    - Usability Note: LGPL-2.1, README and LICENSE present, 54 commits — but only 0 stars and 1 fork, and the GitHub repository now carries a banner redirecting to a GitLab mirror, which is worth checking before relying on the GitHub copy; too new and too low-traffic to assess issue-responsiveness this run.

- **Metabuli v1.2.0 (spaced metamers, reduced alphabets, syncmers)** (Release Date: 2026-03-13) #metagenomics #amr
    - Links: [GitHub](https://github.com/steineggerlab/Metabuli) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.13.711249)
    - Function: Kim & Steinegger (Seoul National University) extend their existing Metabuli metagenomic classifier (joint DNA + amino-acid *metamer* k-mers) with spaced metamers and a reduced amino-acid alphabet for sensitivity, plus syncmer subsampling that halves the reference database size and doubles classification speed — confirmed shipped as Metabuli release v1.2.0, whose changelog explicitly credits this preprint.
    - Use Case: A direct efficiency/sensitivity upgrade to an already-adopted alignment-free metagenomic classifier — relevant to any wastewater, environmental or clinical metagenomic pipeline currently running Metabuli that wants faster runs on a smaller reference database without giving up protein-level sensitivity on divergent taxa.
    - Usability Note: GPL-3.0, comprehensive README, 3,478 commits, 187 stars, 40 open issues, Nature Methods-published lineage (2024) — a mature, actively developed tool; this is an incremental method/version update to a previously-capable tool rather than a first release, flagged here because the new feature set (and its measured 2x speed/size win) is what's new this cycle.

💡 Methodological Trend

The focus-area-10 wave of LLM/agent frameworks wrapping bioinformatics workflows, tracked across many past cycles, continued this run with entrants that specifically target *natural-language interfaces to existing tool/database ecosystems* rather than lab automation. **OmicClaw** (Zeng, Du et al., posted 2026-03-13) layers an executable, reproducible natural-language interface over the unified OmicVerse multi-omics ecosystem, letting a plain-language request drive bulk/single-cell/spatial omics analysis without hand-written glue code. **TogoMCP** (Kinjo, Yamamoto et al., posted 2026-03-19) does the analogous thing for knowledge graphs: schema-guided LLM querying of the RDF Portal (~60 life-science databases maintained by Japan's DBCLS) via the Model Context Protocol, removing the need for SPARQL/RDF-schema expertise to query aggregated life-science data. **Dingent** (Kong, Zhao et al., posted 2026-03-20) is a more general-purpose, easily-deployable database retrieval-and-integration agent framework aimed at the same underlying problem — AI-driven search/integration across heterogeneous backend data sources. None of these were checked for AMR/pathogen-specific applications this run, but together they mark a shift in the agent-framework trend from "agent runs the wet-lab/analysis loop" (seen in several prior cycles) toward "agent is the query/integration layer over existing bioinformatics infrastructure" — worth watching for a veterinary/AMR-specific instance in a future cycle.
