🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

**FastSpeciesTree** (Release Date: 2026-01-20) [EXPERIMENTAL]
Links: [GitHub](https://github.com/OrthoFinder/FastSpeciesTree) | [Preprint](https://www.biorxiv.org/content/10.64898/2026.01.20.700630)
Function: From the OrthoFinder team, infers species trees for tens of thousands of species from raw proteome files alone, using scalable indexed alignments and BUSCO-gene-based concatenation instead of a full all-vs-all orthology run, and reports higher accuracy than several established species-tree methods across disparate benchmark datasets.
Use Case: Building a species tree as a scaffold for comparative genomics, host-range or pathogen-lineage context work when the number of genomes (e.g. a large strain/isolate collection) would make standard orthology-based species-tree pipelines too slow.
Usability Note: GPL-3.0, conda install via provided `.yml`, comprehensive README (Python ≤3.10 required). 31 commits, 11 stars, 1 open issue. README itself flags the tool as "an ongoing project with potential changes to workflow" — label as experimental pending a stable release; no visible issue-response history yet to judge outside-user maintenance.
Tags: #phylogenetics #comparative-genomics #experimental

**FAMeDB** (Release Date: 2026-01-19) [EXPERIMENTAL]
Links: [GitHub](https://github.com/SilvaPereiraLab/FAMeDB) | [Preprint](https://www.biorxiv.org/content/10.64898/2026.01.19.700319)
Function: Curated reference database (FASTA + R scripts) of fungal proteins involved in aromatic-compound metabolism, paired with a Proteinortho-based workflow for annotating a query proteome against it.
Use Case: Screening a fungal genome/proteome for aromatic-compound-degradation potential (e.g. bioremediation, or characterizing an environmental fungal isolate) without building a reference set from scratch.
Usability Note: GPL-3.0, comprehensive README with a 3-step quickstart, 42 commits. Zero stars/forks/watchers and no visible issue history — too new this cycle to assess outside-user maintenance; flagging as experimental on that basis alone (no reported bugs, just no track record yet).
Tags: #annotation #comparative-genomics #experimental

**PePApipe** (Release Date: 2026-01-19, v2)
Links: [GitHub](https://github.com/vilocha/PePApipe-pipeline) | [Preprint](https://www.biorxiv.org/content/10.64898/2026.01.12.698977) | [Protocol](https://www.protocols.io/view/pepapipe-complete-bioinformatics-analysis-pipeline-261geeo57g47/v1.pdf)
Function: Python pipeline integrating 13 established tools (FastQC, fastp, BWA-mem2, Samtools and others) into one automated workflow for African Swine Fever Virus (ASFV) genomes — QC, de novo assembly and variant calling from raw reads to a consensus genome and variant list, runnable locally or via SLURM for batch sample processing.
Use Case: Standardising ASFV genome analysis for laboratories with limited bioinformatics experience, for outbreak tracing and surveillance; the authors explicitly note it can be adapted to other viral species.
Usability Note: GPL-3.0, README covers all 13 component-tool installs. 73 commits, 2 stars, 0 forks — too small a user base yet to judge outside-user issue responsiveness. Note on dating: this preprint's v1 posted 2026-01-14, four days before this window opens (and was missed in the prior [[20260118]] cycle, whose window closed the same day); this entry reflects the 2026-01-19 v2 revision, flagged for transparency rather than presented as a first appearance within this window.
Tags: #annotation #one-health #surveillance-ready

💡 Methodological Trend

- **Graph theory for antibiotic-cycling strategy, not just resistance tracking.** A preprint this cycle ("Precision Evolutionary Medicine", 2026-01-18) builds directed weighted graphs where nodes are antibiotics and edges are collateral-sensitivity trade-offs for three Gram-negative ESKAPE-type pathogens, then searches the graph for 3+-drug "Trap Loop" cycling sequences that keep forcing the pathogen back into a sensitive state, validated only via stochastic 18-month clinical-outcome simulation so far. No code repository was found — this is a modelling proposal, not a released tool — but the idea of treating known collateral-sensitivity relationships as a graph-search problem (rather than a one-drug-at-a-time stewardship rule) is worth watching for AMR management in multi-drug-resistant Gram-negative infections (focus area 9/10).
