🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

- **neissflow** (Release Date: 2026-07-23) [SURVEILLANCE-READY] #amr #nextflow #surveillance-ready
    - Links: [GitHub](https://github.com/cdcgov/neissflow) | [bioRxiv preprint](https://doi.org/10.64898/2026.07.22.740120)
    - Function: Morin, Hetrick, Shrivastava, Tran, Cartee, Hebrank, Gernert, Schmerer, Joseph (US CDC) built a highly parallelized Nextflow pipeline for *Neisseria gonorrhoeae* genome analysis, integrating read QC, species identification, de novo assembly, AMR profiling and recombination-aware phylogenetics with outbreak detection in one nf-core-standard workflow.
    - Use Case: End-to-end, standardized WGS-based surveillance for a WHO critical-priority, essentially pan-resistant pathogen — validated at 100% sensitivity/specificity for species ID against MALDI-TOF/PubMLST, ≥98.1% concordance with PubMLST genotype calls across nine AMR/typing analytes, and 100% accuracy on strain- and intra-MLST-level outbreak clustering, directly lowering the technical barrier for public-health labs doing routine gonococcal AMR surveillance.
    - Usability Note: Apache-2.0, comprehensive README/docs (nf-core conventions, code of conduct), 115 commits, 10 stars, 2 open issues — CDC-maintained with visible multi-author activity; too new to assess issue-responsiveness.

- **MAP (Metabarcoding Analysis Pipeline)** (Release Date: 2026-07-23) #metagenomics #docker
    - Links: [GitHub](https://github.com/cbg-innov/MAP) | [bioRxiv preprint](https://doi.org/10.64898/2026.07.22.740107)
    - Function: Prosser, Bard, Thompson, Floyd, Padhye, Ozsahin, Jafarpour, Hebert (Centre for Biodiversity Genomics, University of Guelph) built a sequence-to-answer metabarcoding workflow, installed as a Docker container, that handles highly multiplexed/replicated study designs and is explicitly tailored to long-read COI metabarcoding as well as short-read amplicons from any marker.
    - Use Case: Flexible biodiversity/eDNA metabarcoding for environmental or host-associated surveillance where existing pipelines are too rigid for the study design or can't handle Nanopore long reads — validated against ground-truth single-specimen barcode data and shown to outperform alternative platforms for COI metabarcoding, directly reusable for environmental or wildlife pathogen/vector surveillance.
    - Usability Note: Stated "free and open-source" in the preprint; 48 commits, 1 star, Docker-only install (`docker pull ghcr.io/cbg-innov/map`) with bundled demo data — brand new, too early to assess issue-responsiveness, and the repository's exact license text could not be confirmed from the README alone.

- **PhyloMLST** (Release Date: 2026-07-23) #amr #variant-calling #python
    - Links: [GitHub](https://github.com/Mattn286/PhyloMLST) | [bioRxiv preprint](https://doi.org/10.64898/2026.07.23.739083)
    - Function: Neil & Evans (University of East Anglia) built a lightweight tool that clusters bacterial isolates into clonal complexes from existing MLST-tool output and maps them to internationally important epidemic lineages ("international clones"), with an option to correct spurious clonal-complex links using a user-provided phylogenetic tree.
    - Use Case: Fills a real gap flagged by the authors — there was previously no convenient tool to assign MLST sequence types to named epidemic lineages (e.g. *A. baumannii* international clones) — directly reusable for any bacterial pathogen where successful, often more-resistant or more-virulent lineages are tracked by clonal complex, not just *A. baumannii*.
    - Usability Note: MIT license, README states "no installation required" (drop-in script + pip dependencies), 11 commits, 1 star — brand new single-author academic release, too early to assess issue-responsiveness.

- **MagicLamp** (Release Date: 2026-07-22) #metagenomics #annotation #python
    - Links: [GitHub](https://github.com/Arkadiy-Garber/MagicLamp) | [Web server](https://midauthorbio.com/#magiclamp) | [bioRxiv preprint](https://doi.org/10.64898/2026.07.19.739457)
    - Function: Garber, Viney, Merino, Ramirez, Pavia, McAllister, Sadeghpour, Manna, Kreger, Wolk, Eunwoo, Qu, Armbruster, Perez-Rodriguez (Arizona State University) built a modular command-line toolkit (also offered as a web server) that performs targeted functional-gene annotation of genomes/metagenomes using curated HMM sets ("genies"), each representing a discrete microbial metabolic process, with reproducible model-specific bit-score thresholds.
    - Use Case: Recovers specialized, ecologically relevant microbial functions that large general-purpose annotation databases overlook — directly reusable for mining metagenomes/MAGs for specific traits of interest (e.g. a particular metabolic or virulence pathway) rather than relying on broad, generic annotation alone.
    - Usability Note: GPL-3.0, comprehensive README (conda install, usage per "genie", config options), 241 commits, 20 stars, 5 open issues (plus 1 open PR) — a mature, actively developed toolkit; issue-responsiveness could not be confirmed from the listing alone.

- **Diversity at the *Acinetobacter baumannii* K locus** (Kaptive database update) (Release Date: 2026-07-21) #amr #variant-calling
    - Links: [GitHub](https://github.com/johannajkenyon/Abaumannii_surface_polysaccharide_loci) | [bioRxiv preprint](https://doi.org/10.64898/2026.07.20.739706)
    - Function: Kenyon (Griffith University) extensively surveyed public *A. baumannii* genomes and added 168 novel capsular-polysaccharide (K) loci to the reference database used by the widely-adopted in-silico typing tool Kaptive, bringing the total to 409 K loci and 10 extra-locus genes, with 309 novel protein clusters newly curated and validated.
    - Use Case: Capsular typing underpins epidemiological surveillance and non-antibiotic intervention design (e.g. phage/depolymerase therapy) for this WHO critical-priority ESKAPE pathogen — validated against 46,185 public genomes, confirming 32 K loci cover 87.1% of sequenced isolates; this is a capability-extension of an existing, established typing database rather than a first release, flagged here because the added diversity and validation against tens of thousands of genomes is what's new this cycle.
    - Usability Note: GPL-3.0, comprehensive README with changelogs, 26 commits, 4 stars — actively curated (author solicits novel-locus submissions); drop-in replacement database for Kaptive users, no separate install needed.

- **DNAS-Bench** (Release Date: 2026-07-20) #emerging #cross-domain #python
    - Links: [GitHub](https://github.com/HenryCWong/DNAS-Bench) | [bioRxiv preprint](https://doi.org/10.64898/2026.07.06.736904)
    - Function: Wong, Kohno, Nivala (University of Washington) built one of the first deterministic benchmarks for Biosecurity Screening Software (BSS) — the systems synthetic-DNA/protein manufacturers use to flag potentially malicious orders — testing BSS robustness against manipulated genomes drawn from the HHS/USDA Select Agents and Toxins List under several evasion strategies (padding, fragmentation, embedding in benign context).
    - Use Case: Directly relevant to focus area 10's dual-use/biosecurity angle: found that two widely used BSS tools (SeqScreen, Commec) flag only 42% and 10.2% of manipulated malicious sequences respectively, and that simply fragmenting a target genome below ~50bp bypasses most existing safeguards — a concrete, reproducible way for BSS developers or biosecurity-conscious labs to stress-test screening pipelines rather than trust vendor claims.
    - Usability Note: MIT license, comprehensive README (Python 3.6+, stdlib-only dependencies), 9 commits, 0 stars — brand new, single framework open-sourced while the underlying manipulated-genome dataset is withheld and available only on request for ethical reasons (documented in `ETHICS.md`); too early to assess issue-responsiveness.

💡 Methodological Trend

Two more releases this cycle extend the "agentic AI for omics analysis" thread flagged in several recent cycles (BacteReason, biomeStat, MechAInistic), and both again stay out of Section A for the same reason as before: no confirmed, dedicated public code release. **ChatGEM** (Chowdhury, George, Purohit et al. — Pacific Northwest National Laboratory, posted 2026-07-21) layers a multi-agent, retrieval-augmented-generation architecture over COBRApy so that genome-scale metabolic model simulation can be driven by natural language rather than code, demonstrated end-to-end on enzyme-constrained *Pseudomonas putida* models for strain engineering — no GitHub repository could be located for it. **MetaClaw** (Zhang, Li, Lagniton et al. — Kang Ning's lab, Huazhong University of Science and Technology, posted 2026-07-24) is an auditable agent for end-to-end metagenomic/multi-omics analysis, splitting work into a deterministic upstream "FlowHub" pipeline and network-isolated downstream "OpenClaw" analysis containers with full per-job provenance logging — recovering known marker sets across four published metagenomic cohorts (sorghum, RRMS, colorectal cancer, permafrost) in its validation. Caution: "MetaClaw" is also the name of an unrelated, already-popular general-purpose self-evolving LLM-agent framework from a different group (AIMING Lab, UNC Chapel Hill) with its own public GitHub repo — that repo is **not** this bioinformatics tool, and the two should not be conflated when this name resurfaces. Neither ChatGEM nor Kang Ning's MetaClaw could be confirmed as openly released this cycle; both are worth rechecking if a licensed code release follows, as agentic orchestration that lowers the bar for GEM simulation or end-to-end metagenomics would be directly useful for labs without dedicated computational staff.
