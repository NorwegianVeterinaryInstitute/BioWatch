- **NanoPlasmiQC** (Release Date: 2026-04-03) #assembly #emerging #python
    - Links: [GitHub](https://github.com/bpucker/NanoPlasmiQC) | [bioRxiv preprint](https://doi.org/10.64898/2026.04.01.715842)
    - Function: de Oliveira, Pucker et al. (University of Bonn, IZMB) present a cost-effective full-plasmid sequencing and automatic-analysis workflow built on Oxford Nanopore long reads (dorado basecalling, minimap2/miniasm/racon assembly), comparing the resulting assembly against the expected plasmid sequence.
    - Use Case: A same-day, per-plasmid-cost alternative to Sanger sequencing for construct verification in any lab doing routine cloning/plasmid QC — relevant to anyone building the synthetic constructs or expression vectors used upstream of pathogen/AMR assay development, though it targets lab plasmids rather than clinical AMR plasmids directly.
    - Usability Note: GPL-3.0, README present, 24 commits — too new to assess issue-responsiveness or ongoing maintenance.

- **SCCmecExtractor** (Release Date: 2026-03-31) #amr #one-health #python
    - Links: [GitHub](https://github.com/AlisonMacFadyen/SCCmecExtractor) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.31.715619) | [PyPI](https://pypi.org/project/sccmecextractor/)
    - Function: MacFadyen (The Sainsbury Laboratory) built a lightweight Python toolkit that locates SCC (Staphylococcal Cassette Chromosome) attachment sites by degenerate pattern matching, extracts the full SCC element sequence from whole-genome assemblies, and characterises its *mec*/*ccr* gene content — something existing SCCmec typing tools do not do.
    - Use Case: Methicillin-resistance mobile-element surveillance across *Staphylococcus* and *Mammaliicoccus* (animal- and human-associated), not just *S. aureus*: benchmarked on 7,297 genomes across 70 species, it found non-*mec* SCC elements (lacking resistance genes but still worth tracking as a mobile-element reservoir) made up 39.4% of all extracted elements overall, rising to 76.0% in *Mammaliicoccus* — directly relevant to AMR mobile-genetic-element surveillance beyond the usual MRSA-only lens.
    - Usability Note: MIT license, comprehensive README (installation, workflows, troubleshooting, citation), 95 commits, 1 open issue, available via PyPI/Docker/Singularity — strong usability signal for a first release.

- **Insights into goatpox virus and sheeppox virus genomes from pangenome graphs** (Release Date: 2026-03-31) #comparative-genomics #evolution #one-health
    - Links: [GitHub](https://github.com/downingtim/GTPV-SPPV-PVG) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.28.714820)
    - Function: Downing (The Pirbright Institute) applies phylogenetics plus pangenome variation graphs (PVGs) to goatpox virus (GTPV) and sheeppox virus (SPPV) — two of the three capripoxvirus species, alongside lumpy skin disease virus (LSDV, tracked by the same author in earlier cycles) — finding GTPV has three deep, stable lineages with a comparatively closed pangenome, while SPPV shows a more recent population expansion and an open pangenome concentrated at the inverted terminal repeats.
    - Use Case: Reusable PVG-based analysis code for comparative/population genomics of large DNA livestock viruses — capripoxviruses are OIE-listed, economically important livestock pathogens, and this is a direct methodological sibling to this author's LSDV pangenome-graph work, extending the same approach to the other two species in the genus.
    - Usability Note: MIT license, README present, 28 commits (R, Python, Shell) — modest but documented; too new/low-traffic to assess issue-responsiveness this run.

- **Panmap** (Release Date: 2026-03-30) #comparative-genomics #variant-calling #metagenomics
    - Links: [GitHub](https://github.com/amkram/panmap) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.29.711974) | [Bioconda](https://anaconda.org/bioconda/panmap)
    - Function: Kramer, Corbett-Detig et al. (UC Santa Cruz) built Panmap, which places, aligns and genotypes sequencing reads against mutation-annotated pangenomes of up to millions of genomes using a phylogenetically compressed k-mer index that stores only the sequence differences along each branch, cutting index size up to 600-fold and build time by over three orders of magnitude versus existing tools.
    - Use Case: Makes large pangenomes directly usable for read mapping, alignment-free phylogenetic placement, genome assembly and metagenomic haplotype deconvolution at a speed existing tools cannot match (a 100x-coverage SARS-CoV-2 sample placed onto 8 million genomes in under two minutes) — directly applicable to wastewater/environmental surveillance and to ancient-DNA placement without prior alignment.
    - Usability Note: GPL-3.0, comprehensive README with CI/CD, Docker and multiple install paths, 1,001 commits, 1 open issue — a mature, actively developed tool from an established pangenome-tooling lab (Corbett-Detig/Turakhia).

- **Novabrowse** (Release Date: 2026-03-30) #comparative-genomics #annotation #python
    - Links: [GitHub](https://github.com/RegenImm-Lab/Novabrowse) | [bioRxiv preprint](https://doi.org/10.64898/2026.03.27.714371)
    - Function: Rikk, Leigh et al. (Lund University) built an interactive BLAST-results interpretation framework bridging the gap between fine-grained alignment viewers and chromosome-scale synteny tools: it retrieves query gene sequences via the NCBI API, BLASTs against chosen subject genomes/transcriptomes, and renders an interactive HTML report with chromosomal maps, ribbon plots and distance-based clustering of hits into putative gene units.
    - Use Case: Resolving gene presence/absence and orthology ambiguity in newly assembled, non-model genomes where annotation reliability lags assembly quality — demonstrated by finding previously undescribed *Foxp3* and *Aire* loci (confirmed by Nanopore long-read RNA-seq) and a lineage-specific *Rbl1* loss in a newt genome; directly reusable for any difficult/non-model genome comparative-annotation task.
    - Usability Note: MIT license, comprehensive README (tutorials, parameter reference, FAQ), 161 commits, 6 stars, Docker/Apptainer and Jupyter deployment options — solid usability signal for a first release.

💡 Methodological Trend

Two entries this cycle both push structure-prediction-at-scale into new discovery territory, a focus-area-10 angle distinct from the LLM-agent wave tracked in prior cycles. **Structure-Led Exploration of the Metagenome Yields Novel RNA-Guided Nucleases with Broad PAM Diversity** (de los Santos, Bowen et al., posted 2026-03-29) used predicted protein folds plus sequence-independent similarity metrics — rather than homology search — to mine metagenomic datasets for extremely low-homology compact RNA-guided nucleases, uncovering PAM-diversity in compact editors comparable to Cas9 and far beyond known transposon-derived systems; no code repository could be confirmed this run (manuscript license is "no reuse" and no GitHub link was found), so it is flagged here as a method rather than a Section A tool. In parallel, **AlphaFold Database expands to proteome-scale quaternary structures** (Han, Tsenkov, Steinegger, Mirdita et al., DeepMind/EMBL-EBI, posted 2026-03-29) extended the AlphaFold Protein Structure Database from single-chain models to genome-scale predicted protein-complex (quaternary) structures, a major public-infrastructure expansion rather than a downloadable tool, but one that structure-led discovery methods like the nuclease-mining paper above will likely draw on directly. Together these suggest "mine the metagenome/proteome by structure, not sequence homology" is maturing from a one-off technique into standard practice — worth watching for a pathogen- or AMR-target-specific application in a future cycle.
