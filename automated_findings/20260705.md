📅 BioWatch — 2026-06-21 to 2026-07-05

🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

- **kmerRRR** (Release Date: 2026-06-25) #comparative-genomics #python
    - Links: [GitHub](https://github.com/LarracuenteLab/kmerRRR) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.21.732238)
    - Function: Rahmat, Pham, Larracuente (University of Rochester) built a k-mer-frequency tool that compares k-mer counts within user-defined loci to their genome-wide frequencies, quantifying "locus uniqueness" to separate sequences that are globally repetitive from those repetitive only at specific loci.
    - Use Case: Recovers mappability and signal in highly repetitive genomic regions (centromeres, heterochromatin) for short-read-based assays (ChIP-seq, small-RNA-seq) that would otherwise lose this data to standard mapping filters — demonstrated on human, *Drosophila* and *Arabidopsis* centromeres, directly reusable for any pathogen or host genome with large repeat-rich or structurally complex regions (e.g. parasite genomes with extensive repetitive content).
    - Usability Note: MIT license, comprehensive README, 30 commits, 6 stars — brand-new from an established repeat-biology lab; too early to assess issue-responsiveness. Python ≥3.6, pip-installable, optional Jellyfish dependency for larger genomes.

- **BATTLE-AMP** (Release Date: 2026-06-24) #amr #snakemake #python
    - Links: [GitHub](https://github.com/szczurek-lab/battleamp-snakemake) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.19.733349)
    - Function: Szymczak, Bukała, Zarzecki, Szczurek et al. (Helmholtz Zentrum München / University of Warsaw) built a benchmarking framework that scores antimicrobial peptide (AMP) predictors against experimentally measured minimum inhibitory concentrations, rather than the binary AMP/non-AMP classification most predictors are evaluated on.
    - Use Case: Directly addresses the reproducibility gap this cycle's survey found in AMP prediction (fewer than 25% of 48 published methods reproducible) — gives anyone screening AMP candidates against a specific pathogen a way to pick a model suited to that target and to score new candidate libraries, rather than trusting a generic classifier's AUROC.
    - Usability Note: MIT license, comprehensive README, 91 commits, 4 stars — released as an open Snakemake framework; conda/pip install documented, no Docker. New this cycle, too early to assess issue-responsiveness.

- **ReSeT** (Release Date: 2026-06-21) #metagenomics #python
    - Links: [GitHub](https://github.com/JaspervB-tud/ReSeT) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.17.732946)
    - Function: van Bemmelen & Baaijens (TU Delft) built a facility-location-based reference genome selection tool that, unlike existing selectors, explicitly optimizes for discrimination *across* taxa (not just representativeness within a taxon), operating on arbitrary pairwise distance matrices with a tunable inter-taxon discrimination term.
    - Use Case: Choosing which reference genomes to include in a profiling database directly determines which taxa a pipeline can tell apart — ReSeT matched or exceeded established selectors on high-ambiguity viral datasets (SARS-CoV-2), making it directly reusable for building taxonomically discriminating reference sets for any high-resolution pathogen surveillance pipeline where closely related strains/lineages must stay distinguishable.
    - Usability Note: MIT license, comprehensive README (CLI, Python API, optional Streamlit dashboard), 158 commits, 4 stars — pip-installable (`reset-bio`) with a conda recipe; active-looking development history despite being new.

- **SPA-C** (Release Date: 2026-06-21) #assembly #python
    - Links: [GitHub](https://github.com/SPA-C/SPA-C) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.16.732382)
    - Function: Mergez, Mourad, Hernandez-Raquet, Zytnicki (INRAE/Univ. Toulouse) built a hybrid genome-scaffolding pipeline that uses a frugal CNN to predict contig linkage from small, local Hi-C contact matrices, then a graph-solving algorithm to generate scaffolds, correcting assembly errors in the same pass rather than as a separate post-processing step.
    - Use Case: Chromosome-level scaffolding from Hi-C for any newly assembled genome (pathogen, host or vector) where existing statistical methods discard informative 2D contact patterns and the one prior deep-learning scaffolder adds a slow, separate correction step — SPA-C outperformed four state-of-the-art methods on a six-genome benchmark at comparable runtime.
    - Usability Note: GPL-3.0, README present, 26 commits, 6 stars, 1 open issue — new release; requires Juicer/HiCExplorer preprocessing plus trained model weights (also on Zenodo). Too early to assess issue-responsiveness.

💡 Methodological Trend

Two releases this cycle extend last cycle's "genomic foundation model" and "agentic AI" threads from pure sequence modelling into harder annotation and orchestration problems (focus area 10). **GENATATORs** (Shmelev, Shadskiy, Kuratov, Kardymon, Fishman — AIRI/HSE, posted 2026-06-21) fine-tunes the GENA-LM DNA language model for *de novo* gene annotation directly from sequence, and reports a genuinely useful negative result alongside the positive one: raw pre-trained DNA-LM embeddings do *not* capture what's needed for precise gene segmentation, task-specific fine-tuning remains essential, and standard per-token/per-sequence evaluation metrics understate real annotation difficulty. The fine-tuned model generalizes across species separated by hundreds of millions of years and segments previously-intractable non-coding transcripts and UTRs — relevant to annotating any newly assembled, poorly-characterized pathogen or host genome, though no standalone licensed code release for GENATATORs itself (as opposed to the general-purpose GENA-LM models) could be confirmed this run, so it stays out of Section A. In the agentic-AI vein flagged by BacteReason and MicroGrowAgents in recent cycles, **biomeStat** (Ariyaratne, Somaratna, Malavige — Advanced Molecular Works, posted 2026-06-23) is an autonomous orchestrator that writes and runs code against established tools (IQ-TREE, TreeTime, BEAST2, HyPhy, PyMOL) in sandboxed, reproducible environments rather than generating biological claims itself — demonstrated end-to-end on 1,000 Asian dengue virus genomes, completing phylogenetics, phylodynamics, selection analysis and structural mapping in under 24 hours. No code repository was found for biomeStat either, so this is a trend to watch rather than a tool to adopt yet: an orchestration layer that reduces weeks of pipeline-wiring to a single session would be directly useful for any lab running routine genomic-epidemiology workflows on arboviruses or other priority pathogens, if and when it is released.

- **Three Plasmid Strategies, One Intermediate Convergence State: Lineage-Specific Resistance, Virulence Architecture in Dominant Indian Carbapenem-Resistant Klebsiella pneumoniae Clones** ([bioRxiv preprint](https://doi.org/10.64898/2026.06.23.734134)) — hybrid-sequencing genomic surveillance study, no software release #amr #one-health
