💡 Methodological Trend

Two threads worth flagging even without a clean Section A entry:

- **Surveillance-tool caution for H5Nx genotyping**: a bioRxiv preprint from
  Finlay Maguire's group (Dalhousie University, with NML Canada) posted
  2026-10-26 found that the two standard H5Nx genotyping tools — **GenoFlu**
  (North America) and **Genin2** (Europe) — assign genotypes by genetic
  similarity that are frequently *incongruent* with the actual phylogeny:
  only 14.2% of GenoFlu clusters and 49.3% of Genin2 clusters were
  monophyletic across segments, and several widely-used genotype labels
  (GenoFlu B3.13, D1.1, D1.3, B3.5, A3; Genin2 EA-2020-C/2021-AB/2022-CH)
  likely lump multiple distinct reassortants together. Relevant for anyone
  using GenoFlu/Genin2 output for H5N1 surveillance decisions (ECDC/EFSA,
  NVI) — the tools remain useful for rapid broad categorization but their
  genotype calls should not be read as a phylogenetic ground truth.
  Link: https://www.biorxiv.org/content/10.64898/2026.10.23.756838v1
- **Genome-aware masking spreading from protein to genome-level pLMs**:
  VenusGenome (see above) extends the pLM idea one level up — modelling
  gene order/strand/contig-boundary context across a whole microbial genome
  rather than per-protein — trained on 1.7M genome assemblies from both
  isolate and metagenomic sources. If a working code release follows, this
  is the kind of representation that could feed into AMR-phenotype-from-
  sequence or metagenomic function-annotation pipelines (focus areas 2–3).

ℹ️ Section B: Informational & Proprietary

**VenusGenome** (https://www.biorxiv.org/content/10.64898/2026.10.24.761516v1) — bioRxiv preprint (cc-by), posted 2026-10-27; pretrained weights on HuggingFace (`z-liang/VenusGenome-85M`, `z-liang/VenusGenome-1.05B`), code repository not confirmed this cycle (candidate GitHub URL 404s).
Function: Gene-resolution masked autoencoder for microbial genome representation learning, using genome-aware attention over contig boundaries, strand orientation and gene position; pretrained on 1.7M isolate + metagenomic genome assemblies.
Tags: #plm #metagenomics #emerging

**H5Nx genotyping incongruence study** (https://www.biorxiv.org/content/10.64898/2026.10.23.756838v1) — bioRxiv preprint (cc-by-nc-nd), posted 2026-10-26; evaluates existing tools GenoFlu and Genin2 rather than releasing a new one.
Function: Shows genetic-similarity-based H5Nx genotype assignments from GenoFlu/Genin2 are often phylogenetically incongruent, risking biased surveillance/risk-assessment conclusions if genotype labels are over-interpreted.
Tags: #evolution #one-health #surveillance-ready

**LDscnR** (https://www.biorxiv.org/content/10.64898/2026.10.27.762116v1) — bioRxiv preprint (cc-by), posted 2026-10-28; R-based method, code repository not located this cycle.
Function: Groups correlated markers in dense genome scans using LD-decay-calibrated thresholds before testing, reducing the number of tests and improving outlier-region precision versus marker-wise association testing (demonstrated on stickleback ecotype data).
Tags: #evolution #r-lang

**Sequence-structured fitness landscapes for influenza** (https://www.biorxiv.org/content/10.64898/2026.10.27.762377v1) — bioRxiv preprint (cc-by), posted 2026-10-28; code repository not located this cycle.
Function: Generative framework inferring mutation-level fitness landscapes for H3N2/H1N1 HA and NA from temporal sequence data, used to forecast which circulating mutations fix or are lost — outperforms neutral/multinomial-logistic baselines in the paper's own comparison.
Tags: #evolution #phylogenetics
