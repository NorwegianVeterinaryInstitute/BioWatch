- **H5N1Americas** (Release Date: 2025-12-23) [SURVEILLANCE-READY] #evolution #phylogenetics #surveillance-ready #HPAI 
    - Links: [GitHub](https://github.com/nidiatrovao/H5N1Americas) | [bioRxiv preprint](https://doi.org/10.1101/2025.12.19.695329)
    - Function: Phylogenetic and phylogeographic analysis scripts/workflows (subsampling, spatial-diffusion reconstruction, flyway-based similarity analysis) behind a 17,516-genome study of the D1.1 reassortant H5N1 genotype, which emerged in the Pacific flyway, spread west-to-east faster than any prior genotype, picked up antigenic change via reassortment with the North American N1 segment, and infected a broader mammalian host range.
    - Use Case: Reproducible phylogeographic tracking of H5N1 reassortant emergence and spread across flyways — directly applicable to NVI's avian-influenza surveillance given H5N1's status as an ECDC/EFSA priority pathogen. [SURVEILLANCE-READY].
    - Usability Note: CC-BY-4.0, README present, 65 commits. Raw GISAID sequence data are licence-restricted so the repo ships accession numbers and scripts rather than alignments (standard practice for GISAID-dependent work, not a usability flaw) — reproducing the analysis requires an authorized GISAID account. Too new to assess issue-responsiveness.

- **epsSMASH** (Release Date: 2025-12-23) #comparative-genomics #metagenomics #python
    - Links: [GitHub](https://github.com/AOHD/epsSMASH) | [Docs](https://docs.epssmash.secondarymetabolites.org/) | [bioRxiv preprint](https://doi.org/10.1101/2025.12.21.693542)
    - Function: Extends the antiSMASH biosynthetic-gene-cluster framework (same DTU Biosustain/antiSMASH developers) to detect and annotate exopolysaccharide (exoPS) biosynthetic gene clusters in bacterial genomes via curated pHMM-colocalization rules at three strictness levels, applied across human-gut, soil, ocean and wastewater-treatment genome catalogues.
    - Use Case: Genome-wide discovery of biofilm-forming exoPS gene clusters — relevant to anyone characterizing biofilm-associated AMR tolerance or environmental/wastewater microbiome genomics, extending the comparative-genomics toolchain many labs already use for antiSMASH-style BGC mining.
    - Usability Note: AGPL-3.0, README present, 128 commits, Docker image on Docker Hub (`antismash/epssmash`) plus a public web-submission service. Built by an established tool-maintenance team (antiSMASH developers), a stronger-than-average signal for ongoing responsiveness, though this specific extension is too new to confirm issue-response behaviour independently.

- **Calbicans_Pooled_CRISPRi_2025** (Release Date: 2025-12-22) #emerging #python
    - Links: [GitHub](https://github.com/TheShapiroLab/Calbicans_Pooled_CRISPRi_2025) | [bioRxiv preprint](https://doi.org/10.1101/2025.12.19.695556)
    - Function: Analysis/visualization code for a pooled CRISPRi screen of 130 fungus-specific genes (no close human homolog) across hundreds of engineered *Candida albicans* strains under ten environmental stressors and multiple clinical genetic backgrounds, identifying 16 drug-target candidates that stayed vulnerable across strains and conditions — including drug-resistant clinical isolates.
    - Use Case: A template pooled-CRISPRi screening/analysis workflow (sgRNA annotation, time-course and WGS variant-calling notebooks) for finding fungus-specific vulnerabilities in any fungal pathogen, not just *C. albicans* — relevant methodology for antifungal-resistant veterinary/zoonotic fungal pathogens even though this release targets a human pathogen.
    - Usability Note: MIT license, README present, 18 commits. This is paper-specific analysis code (Jupyter notebooks, not a packaged general-purpose tool) rather than a standalone CLI — usable as a methodology template more than a drop-in tool. Too new to assess issue-responsiveness.

- **ProFam** (Release Date: 2025-12-21) #plm #python
    - Links: [GitHub](https://github.com/alex-hh/profam) | [PyPI](https://pypi.org/project/profam/) | [bioRxiv preprint](https://doi.org/10.1101/2025.12.19.695431)
    - Function: An open-source family-based protein language model (pfLM) suite — model weights, training/inference code and the curated "ProFam Atlas" training dataset — that conditions sequence scoring and generation on homologous-family context rather than a single sequence, matching state-of-the-art sequence-only methods on the ProteinGym zero-shot fitness-prediction benchmark.
    - Use Case: A fully open alternative to proprietary pLM pipelines for functional annotation and fitness prediction from sequence alone (focus area 2) — e.g. screening candidate AMR or virulence variants for functional impact without a phenotypic assay.
    - Usability Note: MIT license, comprehensive README (install via `pip install profam` or source + `uv sync`), ~1,650 commits, 9 open issues (maintainer-responsiveness not independently confirmed this run given how recent the release is).

- **Stubentiger** (Release Date: 2025-12-21) #amr #evolution #r-lang
    - Links: [GitHub](https://github.com/bacpop/Stubentiger) | [bioRxiv preprint](https://doi.org/10.1101/2025.12.18.695090)
    - Function: An R package implementing a reusable negative-frequency-dependent-selection (NFDS) model of pangenome evolution in *Streptococcus pneumoniae*, used to work out which genomic surveillance sampling strategies (frequency, depth) best detect vaccine-driven replacement as new PCV formulations roll out, from the Lees lab (EMBL-EBI) and collaborators.
    - Use Case: Designing budget-limited genomic surveillance programmes around vaccine introductions by simulating/fitting NFDS dynamics on accessory-gene (including AMR-relevant) frequencies — a generalisable template for any vaccine-preventable bacterial pathogen under genomic surveillance, not just pneumococcus.
    - Usability Note: Apache-2.0, README present, 36 commits, 1 open issue (response not independently confirmed). Installs via `devtools::install_github`, with two additional dependencies pulled from the MRC-IDE R-Universe.

💡 Methodological Trend

A focus-area-10 (emerging & cross-domain) signal worth flagging: a large metagenomics/metatranscriptomics clustering effort (Aplakidou, Baltoumas, Chasapi, Pavlopoulos et al., bioRxiv, posted 2025-12-23, [doi](https://doi.org/10.64898/2025.12.21.695754)) clustered 370 million of 1.7 billion proteins drawn from 44,198 metagenomes/metatranscriptomes into 6.6 million clusters — a 296% increase in known protein-family space, including over 600,000 previously uncharacterised families with ≥100 members. No standalone CLI tool accompanies the paper (the output is a dataset, released via Zenodo/MGnify infrastructure), so it doesn't qualify for Section A, ==but it's a reminder of how much "molecular dark matter" still sits outside reference databases — directly relevant to anyone whose metagenomic classification pipeline reports large fractions of reads as unclassified.== Separately, a single-cell pooled CRISPRa/i screening method for bacteria (mapSPLiT, Brandner et al., bioRxiv, posted 2025-12-22, [doi](https://doi.org/10.64898/2025.12.20.695731)) is the first demonstration of single-cell CRISPR screens in bacteria at scale (100+ transcription-factor perturbations across 76,000 *E. coli* cells, applied also to *Pseudomonas putida*) — no GitHub code release could be confirmed this run, so it's flagged here rather than in Section A, but the underlying microSPLiT/mapSPLiT barcoding approach is worth tracking for bacterial functional genomics generally.

    - Function: A Golden Gate genetic toolkit (Ostrov/Cultivarium Tools lab) of 36 transposase-promoter, 23 antibiotic-resistance-promoter and 12 transposon-destination plasmids, combinable into up to 3,888 barcoded transposon variants, screened as pools to rapidly find a functional transposon-mutagenesis configuration for non-model bacteria. Identified working transposons for 43 strains, including 7 species with no previously described mutagenesis system. Not a software release — flagged here because establishing genetic tractability is usually the first blocker when a novel bacterial isolate (e.g. an unculturable or newly characterized pathogen) needs functional-genomics work at all.

    - Function: Parker, Susumpow et al. spike metagenomic libraries with virus-targeting primers to enrich low-abundance high-risk viral pathogens in wastewater while retaining broad detection capability, aimed at improving sensitivity for One Health wastewater-based surveillance without fully sacrificing the untargeted-discovery advantage of metagenomics. No GitHub repository or pipeline code could be confirmed this run (informational only).
