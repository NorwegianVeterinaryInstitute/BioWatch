- **LoReMINE** (Release Date: 2026-02-02) #annotation #comparative-genomics #python
    - Links: [GitHub](https://github.com/kalininalab/LoReMINE) | [Bioconda/Anaconda](https://anaconda.org/kalininalab/loremine) | [bioRxiv preprint](https://doi.org/10.64898/2026.02.02.703231)
    - Function: Agrawal, Bader, Kalinina (Helmholtz Institute for Pharmaceutical Research Saarland) built an end-to-end pipeline that goes from raw long-read sequencing data (PacBio/Nanopore, with automated assembly-QC) straight through taxonomic classification (NCBI/GTDB) to biosynthetic-gene-cluster (BGC) detection (antiSMASH) and BGC clustering into gene-cluster families (BiG-SLiCE/BiG-SCAPE).
    - Use Case: One command-line pipeline covering assembly-to-BGC-family for microbial natural-product discovery straight from long reads — relevant to anyone mining newly sequenced bacterial/fungal isolates for secondary-metabolite or biocontrol-agent potential without manually chaining five separate tools.
    - Usability Note: MIT license (confirmed via the Bioconda/Anaconda listing; the GitHub repo itself does not show a LICENSE file at the root, worth a second look if adopting), comprehensive README with per-module setup, 61 commits. Too new (first posting this cycle) to assess issue-responsiveness.

- **CAMUS** (Release Date: 2026-02-01) #phylogenetics #evolution
    - Links: [GitHub](https://github.com/jsdoublel/camus) | [bioRxiv preprint](https://doi.org/10.64898/2026.02.01.703143)
    - Function: Willson & Warnow (UIUC) present a divide-and-conquer method for phylogenetic network estimation that scales to far larger taxon sets than existing likelihood-based network inference tools, inferring reticulate events (hybridization, introgression, horizontal gene transfer) on top of a starting species tree from gene-tree quartets.
    - Use Case: Scalable detection of reticulate evolutionary events (e.g. horizontal gene transfer, hybridization) across hundreds-to-thousands of taxa — directly applicable to pangenome/HGT studies in bacterial AMR-gene spread or viral reassortment, where existing network-inference tools don't scale past tens of taxa.
    - Usability Note: MIT license, comprehensive README (inputs/outputs, CLI flags, installation), 239 commits, prebuilt binaries for Windows/macOS/Linux, CI build badge. Strong usability signal for a brand-new method.

- **TandemTwister** (Release Date: 2026-01-28) #variant-calling #comparative-genomics
    - Links: [GitHub](https://github.com/Lionward/TandemTwister) | [Bioconda](https://bioconda.github.io/recipes/tandemtwister/README.html) | [bioRxiv preprint](https://doi.org/10.64898/2026.01.28.702315)
    - Function: Al Raei, Ghareghani et al. (Max Planck Institute for Molecular Genetics) built a scalable genotyper for tandem repeats from long-read data (CLR, CCS, ONT) plus a companion interactive visualizer (ProleTRact), compatible with hg19/hg38/T2T-CHM13 and other TR-genotyping tools' output.
    - Use Case: Genotyping and visualizing tandem-repeat variation (used in DNA fingerprinting and implicated in complex-trait and disease loci) at scale from long-read data — a generalisable addition to any comparative-genomics or strain-typing pipeline needing TR calls alongside SNPs.
    - Usability Note: BSD-3-Clause **non-commercial** license (academic/research use only — flag this before adopting in any revenue-generating context), comprehensive README, 86 commits, 23 stars, 1 open issue. Its earliest confirmed posting (2026-01-28) falls just inside the *previous* cycle's window ([[20260201]], 2026-01-18 to 2026-02-01) but was missed by that cycle's bioRxiv pull — checked directly this cycle and included here rather than silently dropped, following the same correction pattern as cAMRah in [[20260201]].
