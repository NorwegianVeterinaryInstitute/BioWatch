🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

- **Portello** (Release Date: 2026-02-18) #assembly #variant-calling
    - Links: [GitHub](https://github.com/PacificBiosciences/portello) | [bioRxiv preprint](https://doi.org/10.64898/2026.02.18.706714)
    - Function: Saunders, Kronenberg et al. (PacBio) built portello, which transfers HiFi read mappings from a sample's own de novo assembly contigs onto a standard reference genome, unifying assembly-based and conventional reference-mapping inferences into one consistent view and feeding standard mapping-based variant callers (e.g. DeepVariant) without modification.
    - Use Case: Makes long-read de novo assembly usable as a drop-in upgrade to conventional read-mapping variant-calling pipelines — removing 47% of small-variant basecall errors versus conventional mapping in the paper's benchmarks — directly relevant to any difficult/repetitive genome assembly workflow (not just the rare-disease use case in the title) that currently relies on reference mapping alone.
    - Usability Note: README and LICENSE present (11 commits, 1 open issue, too new to assess issue-responsiveness), but **the license is PacBio's own restrictive proprietary terms, not an open-source license**: binary-only redistribution, use restricted to data "generated on a PacBio instrument or otherwise provided to you by PacBio", no modification/reverse-engineering rights, liability capped at $5. Flag this before adopting — it is more restrictive than a standard non-commercial OSS license (compare [[20260215]]'s TandemTwister) and effectively vendor-locks the tool to PacBio data.

- **rustybam / SafFire** (Release Date: 2026-02-16) #comparative-genomics #assembly
    - Links: [GitHub (rustybam)](https://github.com/vollgerlab/rustybam) | [GitHub (SafFire)](https://github.com/vollgerlab/SafFire) | [Bioconda](https://anaconda.org/bioconda/rustybam) | [crates.io](https://crates.io/crates/rustybam) | [bioRxiv preprint](https://doi.org/10.64898/2026.02.16.706142)
    - Function: Vollger (University of Utah) built rustybam, a Rust command-line toolkit for CIGAR-aware manipulation of PAF/BAM alignments (overlap resolution, coordinate liftover, alignment splitting at structural variants, scaffolding, identity statistics), paired with SafFire, a browser-based interactive genome-comparison visualizer with annotation overlays.
    - Use Case: A composable, scriptable alternative to ad hoc alignment-wrangling scripts for anyone doing genome-to-genome comparison or structural-variant-aware alignment post-processing — directly reusable in comparative-genomics or pangenome pipelines for difficult/repetitive genomes.
    - Usability Note: MIT license, comprehensive README, 417 commits (rustybam), 2 open issues, available via Bioconda/crates.io/precompiled binaries plus a Dockerfile — strong usability signal from an established genome-assembly-tooling author (Vollger has prior authorship on verkko-adjacent assembly/QC tools).

- **kache-hash** (Release Date: 2026-02-13) #comparative-genomics #metagenomics
    - Links: [GitHub](https://github.com/jamshed/kache-hash) | [bioRxiv preprint](https://doi.org/10.64898/2026.02.13.705625)
    - Function: Khan, Patro (Northeastern/UMD, salmon/pufferfish lab) and Pandey present kache-hash, the first dynamic, concurrent, resizable hash table that exploits k-mer locality via minimizer-based bucketing (built on Iceberg hashing), achieving 1.58-2.62x higher insertion throughput and up to 6.1x higher query throughput than the prior state of the art, with 7.39x fewer cache misses, on the human genome.
    - Use Case: Foundational infrastructure for any streaming k-mer-based workflow (metagenomic classifiers, pangenome/colored de Bruijn graph indexing, read classification) that needs a hash table supporting dynamic updates during streaming — a building block rather than an end-user pipeline, but one that downstream comparative-genomics and metagenomics tools could adopt directly.
    - Usability Note: GPL-3.0 license, comprehensive README, 375 commits, 1 open issue, C++20 with a C API wrapper and Rust bindings. Its earliest confirmed posting (2026-02-13) falls just inside the *previous* cycle's window ([[20260215]], 2026-02-01 to 2026-02-15) but was missed by that cycle's bioRxiv pull — checked directly this cycle and included here rather than silently dropped, following the same correction pattern as TandemTwister and cAMRah in earlier cycles.

💡 Methodological Trend

The focus-area-10 wave of LLM/agent frameworks doing bioinformatics work, tracked across several past cycles ([[20260118]]: ToolsGenie 2.0, NetMedGPT, BiomeGPT; [[20260201]]: Medea, BiOmics, PersonaAI; [[20260215]]: a GPT-5-driven autonomous CFPS lab, BOLE for breeding), continued this cycle with two more entrants extending the pattern into new domains. **The Web of Microbes Agent** (Northen, Bowen et al., LBNL, posted 2026-02-24) pairs a Bayesian-ranking substrate-preference model with the Phydon growth model and an LLM for autonomous tool-calling, correctly predicting which bacteria get enriched in soil metabolite spike-in experiments and reasoning about which substrates would selectively promote one clade over another — no standalone public code repository could be confirmed this run (it builds on the pre-existing Web of Microbes database/webserver at webofmicrobes.org, not a new installable package). **CellSwarm** (Meng, Wang et al., posted 2026-02-25) replaces the hand-coded rules of traditional agent-based tumor-microenvironment models with LLM-driven cell agents that can sense indirect genetic perturbations — again no confirmed code release this run. Separately, a third item is worth flagging as a genuinely new angle rather than a repeat of the "AI does the analysis" pattern: **Evaluating AI-Assisted Customer Verification for Synthetic Nucleic Acid Screening** (Acelas, Nelson et al., Centre for Long-Term Resilience, posted 2026-02-27, now published in *Frontiers in Bioengineering and Biotechnology*) tested LLMs (best: Gemini 2.5 Pro with bibliographic/sanctions APIs) against a human expert baseline for legitimacy-screening customers ordering synthetic nucleic acids — matching human flag accuracy (90.2% vs 89.0%) at roughly one-tenth the cost. This is AI applied to *biosecurity governance* itself (dual-use screening at synthesis providers), a distinct cross-domain application from the lab-automation and multi-omics-interpretation agents seen in prior cycles, and relevant to anyone tracking dual-use biosecurity safeguards rather than just analytical throughput.
