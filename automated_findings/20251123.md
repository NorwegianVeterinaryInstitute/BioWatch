📅 BioWatch — 2025-11-09 to 2025-11-23

🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

- **MADRe** (Release Date: 2025-11-10, v2 preprint update) #metagenomics #python #r-lang [EXPERIMENTAL]
    - Links: [GitHub](https://github.com/lbcb-sci/MADRe) | [bioRxiv preprint](https://doi.org/10.1101/2025.05.12.653324)
    - Function: A strain-level metagenomic classification pipeline that combines assembly-driven database reduction with probabilistic read mapping, aimed at samples with no prior knowledge of community composition.
    - Use Case: Strain-resolved classification in complex/novel metagenomes (e.g. wastewater or environmental surveillance) where standard reference-database approaches under- or over-call strain presence.
    - Usability Note: MIT license, README + tutorial present, conda/source install. Active: commits through 2025-11-06 including a documentation pass and a `--use-myloasm` bug fix. [EXPERIMENTAL] tag applied cautiously — tool is young (first preprint 2025-05, this is a v2 update) and issue-responsiveness could not be independently confirmed this run.

- **Seqwin** (Release Date: 2025-11-09) #metagenomics #one-health #python
    - Links: [GitHub](https://github.com/treangenlab/Seqwin) (Bioconda available) | [bioRxiv preprint](https://doi.org/10.1101/2025.11.07.687294)
    - Function: Builds weighted pan-genome minimizer graphs to automatically discover microbial "signature sequences" — regions common within a target organism but rare outside it — for PCR-based diagnostic assay design, tolerating natural sequence variation rather than requiring strict presence/absence patterns.
    - Use Case: Rapid, scalable PCR-target discovery for pathogen diagnostics; demonstrated on *C. difficile*, *M. tuberculosis* and ~15,000 *S. enterica* genomes in ~5 minutes — directly relevant to designing targeted assays for priority pathogens.
    - Usability Note: GPL-3.0 license, README present, 153 commits, Bioconda packaging. One open feature-request issue (faster BLAST alternative) with no visible maintainer reply yet — too early in the issue's life to call unmaintained, but worth re-checking next cycle rather than labeling [EXPERIMENTAL] now.

- **HapBridge** (Release Date: 2025-11-07) #assembly #python [EXPERIMENTAL]
    - Links: [GitHub](https://github.com/Humonex/HapBridge) | [bioRxiv preprint](https://doi.org/10.1101/2025.11.07.687303)
    - Function: Uses DNA methylation signal (haplotype-specific methylation consistency) to detect and correct switch errors and bridge adjacent phased blocks in long-read (ONT/PacBio HiFi) haplotype phasing, targeting low-heterozygosity regions where standard SNP-based phasing struggles.
    - Use Case: Improving haplotype-resolved assemblies in low-heterozygosity genomic regions — adjacent to, though not identical to, this report's standing haplotig-purging/diploid-parasite priority; no genome-specific (e.g. cestode) application has been published yet, so treat as a general phasing building block rather than a parasite-ready pipeline.
    - Usability Note: GPL-3.0 license (code repo; preprint text itself carries a separate "all rights reserved" display-rights notice, which is normal and does not apply to the code), README present, commits through 2025-11-14 (just after this window — early active development). [EXPERIMENTAL] — first release, no issue history yet to assess maintenance.

💡 Methodological Trend

A hidden Markov model for detecting within-host SARS-CoV-2 recombination and parental-lineage assignment (Masaki & Bedford, bioRxiv, posted 2025-11-10, [preprint](https://doi.org/10.1101/2025.11.08.687354), [code](https://github.com/nobuakimasaki/HMM-recombination)) is worth flagging methodologically even though it doesn't qualify for Section A — no LICENSE file could be found in the repository, so it fails this report's usability bar. The approach itself (parameter-free HMM recombination/ancestry calling that tolerates novel mutations not seen in either parent) is a reminder that recombination detection keeps moving away from fixed-breakpoint heuristics toward likelihood-based models — relevant to any group doing segment-reassortment or recombination work (H5N1, other RNA viruses) even though this specific implementation isn't yet usable off-the-shelf.
