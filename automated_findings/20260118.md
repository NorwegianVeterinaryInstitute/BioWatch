📅 BioWatch — 2026-01-04 to 2026-01-18

🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

**DeepKOALA** (Release Date: 2026-01-07)
Links: [GitHub](https://github.com/zhaoxi120/deepkoala) | [GenomeNet web server](https://www.genome.jp/tools/deepkoala/) | [Preprint](https://www.biorxiv.org/content/10.64898/2026.01.07.698072)
Function: GRU-based deep learning tool for KEGG Orthology (KO) assignment, framing annotation as an open-set recognition problem rather than pure alignment/HMM matching — handles fragmented sequences and multi-domain proteins and reports accuracy comparable to alignment-based tools (KofamKOALA-style) at substantially higher throughput.
Use Case: Fast functional annotation pass for large assemblies or metagenomic gene catalogs where alignment-based KO assignment (BlastKOALA/KofamKOALA) is too slow — useful as a first-pass annotation step ahead of focused comparative-genomics work.
Usability Note: MIT license, 88 commits, 26 stars, pip-installable with CLI and Python API, pretrained model weights dated February 2025 and regularly updated. No visible issue-response history this cycle to judge outside-user maintenance.
Tags: #annotation #python

**LORA** (Release Date: 2026-01-06)
Links: [GitHub](https://github.com/sequana/lora) | [PyPI](https://pypi.org/project/sequana-lora/) | [Preprint](https://www.biorxiv.org/content/10.64898/2026.01.06.697901)
Function: Snakemake-based, multi-sample long-read assembly pipeline from the Sequana project (Institut Pasteur) — runs Canu/Flye/Hifiasm on PacBio or ONT input, with built-in polishing, coverage analysis and BUSCO scoring, and produces per-sample HTML reports across many samples at once rather than one genome at a time.
Use Case: Standardising long-read assembly QC across a batch of isolates or samples (e.g. an outbreak collection) instead of re-running and re-reporting each assembly individually — directly useful for any multi-isolate genome assembly project.
Usability Note: BSD-3-Clause, pip-installable (`sequana-lora`), 158 commits, comprehensive README, but only 5 stars and 13 open issues with no visible maintainer-response evidence this cycle — part of the established Sequana pipeline suite (lower adoption risk than a standalone new tool) but outside-user issue responsiveness not confirmed.
Tags: #assembly #snakemake #python

**MetaNetMap** (Release Date: 2026-01-05)
Links: [GitHub](https://github.com/coraliemuller/metanetmap) | [Docs](https://metanetmap.readthedocs.io) | [Preprint](https://www.biorxiv.org/content/10.64898/2026.01.05.697697)
Function: Python tool that automatically maps metabolite identifiers from metabolomic data onto genome-scale metabolic networks (GSMNs), including a community mode for mapping against collections of networks and optional partial-matching strategies to improve mapping rates.
Use Case: Reconciling metabolomics output with an existing metabolic-network model (single organism or microbial community) without hand-curating identifier mappings — relevant to any multi-omics integration work pairing metabolomics with a reconstructed network.
Usability Note: LGPLv3, pip-installable (`pip install metanetmap`), 150 commits, CI/CD configured, ReadTheDocs documentation. Only 5 stars/0 forks and no visible issue history this cycle — too early to judge outside-user maintenance.
Tags: #comparative-genomics #python

**TAFFISH** (Release Date: 2026-01-04, v2)
Links: [GitHub org](https://github.com/taffish) | [Hub](https://taffish.github.io/flows/) | [Preprint](https://www.biorxiv.org/content/10.1101/2025.09.15.672424)
Function: Packages command-line bioinformatics tools and their fixed runtime environments as modular, container-backed, shell-native "apps" and "flows" — positioned between raw shell scripts and heavyweight workflow managers (Nextflow/Snakemake), with a package index (TAFFISH-Hub) already covering 60+ common tools (csvtk, somalier, TransDecoder, etc.).
Use Case: Making ad hoc shell-script-based analyses (the kind that are hard to preserve, inspect or reuse) reproducible and shareable without migrating the whole workflow to Nextflow/Snakemake.
Usability Note: Apache-2.0, ~283 repositories across the org, active-looking package ecosystem. Note on dating: the underlying preprint first posted 2025-09-15 (outside prior windows) — this entry reflects a 2026-01-04 v2 revision, not first appearance; flagging for transparency. Outside-user issue responsiveness not assessed this cycle.
Tags: #emerging #python

💡 Methodological Trend

- **Likelihood-free, transformer-based phylodynamics.** Teddy (Garot, Blassel et al., Collège de France, posted 2026-01-05) replaces the usual phylogeny-reconstruction-plus-likelihood pipeline for estimating epidemiological parameters (R0, infection duration) with a neural network trained by simulation on dated viral sequence alignments — matching BEAST2-level accuracy roughly 1000x faster, with no public code repository found yet. Worth watching once released: a drop-in, much faster alternative for outbreak parameter estimation (focus area 6/10) that skips tree-building entirely.
- **Protein language models applied to pangenome-scale strain variation, not just single proteins.** A 2026-01-15 preprint builds strain-level ProtT5 embeddings across 9,558 *E. coli* isolates to link pangenome functional diversity to host-microbe phenotypes (chaperone/protease activity affecting a nematode host's proteostasis) — illustrating pLMs being used for whole-pangenome functional stratification rather than single-sequence annotation. No standalone software package was identified this cycle (analysis pipeline, not a released tool), but the approach is a template for using pLM embeddings to summarise strain-level functional diversity in AMR-relevant species (focus area 2/7).
