📅 BioWatch — 2026-01-04 to 2026-01-18

🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

- **DeepKOALA** (Release Date: 2026-01-07) #annotation #python
    - Links: [GitHub](https://github.com/zhaoxi120/deepkoala) | [Web server](https://www.genome.jp/tools/deepkoala/) | [bioRxiv preprint](https://doi.org/10.64898/2026.01.07.698072)
    - Function: A GRU-based deep learning tool for fast protein function annotation via the KEGG Orthology (KO) system, from the KEGG/GenomeNet group (Kanehisa, Ogata et al.), matching alignment-based tools (e.g. BlastKOALA) on accuracy at substantially higher throughput, with dedicated handling for fragmented sequences and multi-domain proteins.
    - Use Case: Fast, large-scale functional annotation of newly sequenced or assembled genomes against a curated pathway/function framework — directly useful for annotating pathogen or AMR-associated gene content at scale without the alignment-search bottleneck of classic KO assignment.
    - Usability Note: MIT license, comprehensive README (install, CLI/Python API, citation), 88 commits, downloadable model weights alongside the GenomeNet web server. Built by the core KEGG/GenomeNet team — a stronger-than-average maintenance signal, though issue-responsiveness for this specific tool is not yet independently confirmed given how recent the release is.

- **LORA (sequana-lora)** (Release Date: 2026-01-06) #assembly #snakemake #python
    - Links: [GitHub](https://github.com/sequana/lora) | [PyPI](https://pypi.org/project/sequana-lora/) | [Demo](https://sequana.github.io/lora-demo) | [bioRxiv preprint](https://doi.org/10.64898/2026.01.06.697901)
    - Function: A polymorphic, multi-sample long-read assembly pipeline (Snakemake, part of the Institut Pasteur Sequana project) that lets users choose among Flye/Canu/Hifiasm/Unicycler/NECAT/PECAT per sample, with optional circularisation (Circlator), Illumina-based polishing (Polypolish) and rich interactive HTML reports at every step.
    - Use Case: One pipeline covering ONT and PacBio HiFi long-read assembly with assembler choice per sample and built-in QC reporting — useful for routine genome assembly of difficult or repetitive pathogen/parasite genomes without having to hand-roll a Snakemake workflow around each assembler.
    - Usability Note: BSD-3-Clause, comprehensive README (install, SLURM/HPC, containerisation, changelog), 158 commits, 13 open issues (maintainer-responsiveness not independently confirmed this run, but changelog shows active version-to-version maintenance through v1.2.0).

- **MetaNetMap** (Release Date: 2026-01-05) #comparative-genomics #python
    - Links: [GitHub](https://github.com/coraliemuller/metanetmap) | [Docs](https://metanetmap.readthedocs.io/) | [bioRxiv preprint](https://doi.org/10.64898/2026.01.05.697697)
    - Function: A Python tool (Inria Pleiade / INRAE META) that automatically maps metabolomic annotation data onto genome-scale metabolic networks (GSMNs), reconciling the different identifier systems used by metabolomics pipelines and network models, in both single-network and multi-network "community" modes (via MetaNetX/MetaCyc conversion tables).
    - Use Case: Linking untargeted-metabolomics output to community-level metabolic network models — relevant to anyone doing microbiome functional/metabolic reconstruction (e.g. gut or environmental community metabolic modelling) who currently has to hand-reconcile metabolite IDs between the two data types.
    - Usability Note: LGPLv3, ReadTheDocs documentation, companion reproducibility repository for the paper's analyses. Too new (first posting this cycle) to assess issue-responsiveness.

💡 Methodological Trend

A focus-area-10 (emerging & cross-domain) cluster worth naming this cycle: three independent groups released AI-foundation/agent systems aimed at making bioinformatics itself more automatable rather than studying a specific organism. **ToolsGenie 2.0** (Ma, Han et al., bioRxiv, posted 2026-01-07, part of the PromptBio platform) is a ReAct-style multi-agent system that autonomously plans and executes bioinformatics analyses from a natural-language query plus input files, with an "ExecutorAgent" that generates custom analysis code on the fly — but no standalone GitHub repository could be confirmed this run (it appears bundled into the broader, not-yet-independently-released PromptBio platform), so it doesn't qualify for Section A. In the same vein, **NetMedGPT** (Firoozbakht, Baumbach et al., posted 2026-01-04) and **BiomeGPT** (Medearis, Zomorrodi et al., posted 2026-01-05) are both new transformer foundation models — one for mining disease mechanisms/drug repurposing from biomedical knowledge graphs, the other pretrained on 13,300+ human gut metagenomes for species-level microbiome representation learning — but neither has a confirmed public code release yet, worth rechecking in a later cycle. Taken together, this is an early but genuinely new wave (self-directed bioinformatics agents, and metagenome-scale foundation models) distinct from the pLM-for-single-protein work covered in past cycles.

    - Function: Garot, Jacob, Alizon et al. (Sorbonne Université) present a likelihood-free neural posterior estimation method ("Transformers for EpiDemiological DYnamics") that infers epidemiological parameters (e.g. R0, transmission rate) directly from dated viral sequences using self-attention, without reconstructing a phylogeny — matching BEAST2's inference on simulated and early-COVID data roughly three orders of magnitude faster. README present, 11 commits, but no LICENSE file found in the repository, so it fails this report's strict Section A usability bar despite being a methodologically interesting phylodynamics shortcut relevant to any outbreak-response pipeline currently bottlenecked on tree-based BEAST runs.

No GitHub repository confirmed this run (informational only); existing community tools for this problem include [STECode](https://github.com/CIDM-PH/Stecode) and [AlleleFinder](https://github.com/OLC-Bioinformatics/AlleleFinder), both predating this window.

    - Function: Aebischer, Beer et al.
