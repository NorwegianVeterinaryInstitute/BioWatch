- **Core genome MLST scheme for the Enterobacter cloacae complex** (Release Date: 2026-09-20) #variant-calling #amr #webserver
    - Links: [chewBBACA online scheme](https://chewbbaca.online/species/21) | [bioRxiv preprint](https://doi.org/10.64898/2026.09.14.751580)
    - Function: Miller, Bakker, Dyet, Winter (New Zealand Institute for Public Health and Forensic Science) built a 1,812-locus cgMLST scheme from 3,442 public genomes spanning 27 species/subspecies of the Enterobacter cloacae complex (ECC), hosted on the established chewBBACA nomenclature server rather than as a standalone repository.
    - Use Case: Resolved outbreak-linked isolates to 0-3 allelic differences on two independent evaluation datasets, matching cgSNP-level resolution — gives public-health and veterinary labs a standardized, WGS-based typing scheme for this healthcare-associated, carbapenemase-prone pathogen complex where species identification by phenotype alone is unreliable.
    - Usability Note: This is a typing scheme on a maintained public platform (chewBBACA/Chewie Nomenclature Server), not a GitHub project — no separate README/LICENSE/commit history to assess; the server itself resolved and loaded the species-21 listing, but its specific access/download terms could not be independently confirmed beyond that. Preprint itself is CC-BY-ND (no derivatives), which does not affect use of the hosted scheme itself.

- **DeepVir** (Release Date: 2026-09-18) #disease-x #one-health #snakemake
    - Links: [GitHub](https://github.com/matheus-cosentino/discovir) | [bioRxiv preprint](https://doi.org/10.64898/2026.09.15.751837)
    - Function: Cosentino, Fernandez Nunez, Soares, Ayouba, Santos, D'arc (Universidade Federal do Rio de Janeiro) built a Snakemake pipeline that combines classical homology-based alignment with profile-HMM mining of RNA-dependent RNA polymerase (RdRp) to automate discovery of highly divergent ("viral dark matter") sequences from HTS data, replacing manual chained command-line workflows.
    - Use Case: Mined 385 GB of public transcriptomic data from 49 American bat species, finding 179 distinct viral groups including novel genomes in seven families and the first putative exogenous Spumavirus in the Americas — a directly reusable pipeline for any lab doing unbiased wildlife-reservoir virus surveillance where no close GenBank relative exists to anchor a standard search.
    - Usability Note: GPL-3.0 license, comprehensive README with pipeline diagram and tutorials, 750 commits, 4 stars, 0 forks — active development on the code itself, but no issue history yet to judge maintainer responsiveness either way.

- **PyEuk** (Release Date: 2026-09-16) #variant-calling #one-health #python
    - Links: [GitHub](https://github.com/spond/pyeuk) | [bioRxiv preprint](https://doi.org/10.64898/2026.09.10.750732)
    - Function: Kosakovsky Pond, Callan, Nekrutenko (Pennsylvania State University) built a catalogue-free multilocus microhaplotyping suite that calls haplotypes directly from sequence differences against a reference, and can reconstruct amplicon target panels de novo from read-coverage peaks when panel coordinates are uncharacterized — removing the need for a centrally curated allele catalogue.
    - Use Case: Validated on Cyclospora cayetanensis (resolving independent transmission chains across national foodborne-outbreak archives exceeding 8,000 isolates) and Plasmodium vivax (discriminating relapse from reinfection); directly useful for any lab surveilling emerging or uncultivable eukaryotic parasites that have no established MLST scheme, reimplementing legacy R clustering 230-400x faster.
    - Usability Note: Apache-2.0 license, extensive README (quickstart, Galaxy workflows, Python API), 304 commits, 4 stars, 3 forks, versioned v0.8.1, Galaxy-integrated and containerized — actively developed. One open issue, filed by a co-author himself rather than an unanswered user complaint, so not a maintenance red flag.

- **FlavoTyper** (Release Date: 2026-09-16) #variant-calling #one-health #python
    - Links: [GitLab](https://forge.inrae.fr/eric.duchaud/flavotyper) | [bioRxiv preprint](https://doi.org/10.64898/2026.09.14.751350)
    - Function: Mbarki, Debeljak, Carpentier, Jolley, Haddad, Rochat, Duchaud (INRAE / Université Paris-Saclay) built an in-silico serotyping tool for the fish pathogen Flavobacterium psychrophilum, deriving O-antigen serotype directly from genome assemblies via biomarkers in the O-antigen biosynthesis locus, replacing costly, non-standardized wet-lab serotyping.
    - Use Case: Applied across all public F. psychrophilum assemblies, serotype calls matched known host-fish associations (e.g. coho salmon with O:0) and revealed the O-antigen locus rearranges independently of core-genome lineage — directly useful for aquaculture surveillance and vaccine-strain selection, an under-served food-security niche for BioWatch.
    - Usability Note: Apache-2.0 license, README present, 126 commits, 3 tags/releases, also distributed via PyPI/bioconda and integrated into PubMLST's BIGSdb (signal of real uptake). Repository is only ~7 months old (created 2026-02-24) with no visible issue history — too young to assess maintainer responsiveness either way.
