🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

- **LSDV pangenomics workflow** (Release Date: 2025-11-27) #comparative-genomics #amr #python
    - Links: [GitHub](https://github.com/downingtim/LSDV_pangenomics) | [bioRxiv preprint](https://doi.org/10.1101/2025.11.26.690900)
    - Function: Builds pangenome variation graphs (PVGs) from multiple lumpy skin disease virus (LSDV) genomes and maps Illumina reads with Giraffe, benchmarked against linear-reference mapping with Minimap2, to recover SNPs invisible to single-reference approaches — the first PVG applied to a large DNA virus.
    - Use Case: Genomic surveillance, outbreak tracing and detection of recombinant/vaccine-related lineages for LSDV and, by extension, other large DNA viruses of veterinary concern, where reference bias from divergent or recombinant isolates causes standard variant calling to under-call diversity.
    - Usability Note: MIT license, README present, workflow organised into four scripted stages (mapping, downstream analysis, variant annotation, figures). 96 commits with activity continuing well past this window (latest seen through mid-2026), no open issues yet to assess responsiveness — too new to call [EXPERIMENTAL] or not. From The Pirbright Institute (UK's main livestock-virus research centre); directly relevant to any group doing recombination/segment-reassortment or variant-analysis work on large DNA viruses.

💡 Methodological Trend

A small but notable focus-area-10 (emerging & cross-domain) signal this cycle: general-purpose LLMs doing protein engineering **without any domain-specific biological training**. [Li & Dong, bioRxiv, posted 2025-11-24](https://doi.org/10.1101/2025.11.23.689994) show DeepSeek V3.2 (in reasoning mode) generating viable 4-helix-bundle sequences (36/49 candidates with pLDDT > 70) and solubility-improving point mutations, purely from a text prompt plus standard structural validation (AlphaFold-type scoring). No code release accompanies this (prompt-based use of an existing commercial/open-weight LLM, not a new tool), so it doesn't qualify for Section A, but it's a data point worth tracking: the boundary between "general-purpose LLM" and "purpose-built protein model" (ESM-2, ProtBERT, etc.) keeps getting blurrier, with implications for how accessible ad-hoc sequence-design work becomes for groups without pLM infrastructure.

ℹ️ Section B: Informational & Proprietary

- **STELAR-X** ([GitHub](https://github.com/aaniksahaa/STELAR-X) | [bioRxiv preprint](https://doi.org/10.1101/2025.11.22.689894)) — no declared license #phylogenetics #emerging
    - Function: A GPU-accelerated, statistically consistent species-tree inference method (successor to STELAR/ASTRAL-style summary methods) that scales coalescent-based phylogenomic inference to 100,000 taxa — reported 3,576× faster than ASTRAL-MP with 13.9× less memory on 10,000-taxa benchmarks. README and active repo (207 commits) present, but no LICENSE file in the repository, so it fails this report's strict Section A usability bar despite otherwise looking like a solid, usable tool; worth a second look if a license is added.
- **RegEvol** ([GitHub](https://github.com/mrrlab/RegEvol) | [bioRxiv preprint](https://doi.org/10.1101/2025.11.26.690685)) — no declared license #evolution #emerging
    - Function: Links machine-learning predictions of transcription-factor binding to explicit evolutionary fitness models to detect directional selection in regulatory (non-coding) DNA, distinguishing it from drift/stabilising-selection scenarios. Applied to >3M Drosophila regulatory regions and human CTCF sites. README present, 1,224 commits, but likewise no LICENSE file — same caveat as STELAR-X above.
- **Nomenclature update for H5 HPAI clades 2.3.2.1c/2.3.4.4** ([bioRxiv preprint](https://doi.org/10.1101/2025.11.23.690055)) — informational, not software #one-health #surveillance-ready #HPAI #Classification

Relevant to any pipeline that hard-codes current H5Nx clade names for surveillance reporting — [SURVEILLANCE-READY] (ECDC/EFSA/NVI priority pathogen).
