🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

**Floco** (Release Date: 2025-11-21)
Links: [GitHub](https://github.com/hugocarmaga/floco) | [Preprint](https://www.biorxiv.org/content/10.1101/2025.11.21.689771)
Function: Calls copy number relative to a graph (pan)genome by formulating the problem as a network flow optimization solved with ILP, instead of relying on read depth alone. Validated on HiFi, ONT and linear-assembly-derived reads across three graphs, with CN accuracy up to 43% higher than depth-based estimation and 93.2% concordance across sequencing sources.
Use Case: Copy-number variant calling against a pangenome graph reference rather than a single linear reference — relevant wherever a species/strain pangenome graph already exists (e.g. structural variation in complex or duplicated regions).
Usability Note: Conda recipe (bioconda `floco`), README covers install/usage/test data. Too new in this window to assess maintenance responsiveness — no issue history to judge yet.
Tags: #variant-calling #comparative-genomics #python

**Using pangenome variation graphs to improve mutation detection in a large DNA virus** — tool: **Panalyze** (Release Date: 2025-11-26)
Links: [GitHub (Panalyze)](https://github.com/downingtim/Panalyze) | [GitHub (LSDV analysis code)](https://github.com/downingtim/LSDV_pangenomics) | [Preprint](https://www.biorxiv.org/content/10.1101/2025.11.26.690900)
Function: Builds a pangenome variation graph (via PGGB) from related viral genomes and uses it to call mutations, instead of mapping reads to one linear reference. Applied here to lumpy skin disease virus (LSDV), a transboundary cattle poxvirus, where PVG-based mapping found more SNPs than linear mapping, including variants in host-recognition and immune-evasion genes.
Use Case: Improves SNP discovery for large, structurally complex DNA viruses (poxviruses, herpesviruses) where a single reference genome underrepresents real strain diversity — directly useful for livestock virus surveillance and source attribution.
Usability Note: Nextflow + Docker, MIT license, README present, 124 commits on main. The Panalyze tool itself was first described in an April 2025 preprint; this November entry is a new scientific application (LSDV mutation detection) released within this window, not a re-listing of the tool's own debut.
Tags: #comparative-genomics #evolution #nextflow

**Verkko-Fillet** (Release Date: 2025-11-25, v2)
Links: [GitHub](https://github.com/jjuhyunkim/verkko-fillet) | [Docs](https://verkko-fillet.readthedocs.io/) | [Preprint](https://www.biorxiv.org/content/10.1101/2025.10.01.679366)
Function: Python/Jupyter toolkit for cleaning, fixing and gap-filling genome assemblies produced by the Verkko assembler — graph inspection and editing from GFA/GAF/FASTA inputs, plus guided manual polishing steps. Demonstrated by finishing a telomere-to-telomere giraffe genome (QV 61.5 draft → QV 73.6 T2T).
Use Case: Closing the gap between a high-coverage draft assembly and a truly complete, telomere-to-telomere reference — relevant to any complex or difficult genome project, not just the giraffe case study.
Usability Note: MIT license, README present, 417 commits, pip/PyPI install (`verkkofillet`). Note on dating: the underlying preprint originally posted 2025-10-01 (outside this window) — the 2025-11-25 date reflects a substantive v2 revision (new CLI utilities, updated docs) rather than first appearance; flagging for transparency rather than presenting it as brand-new. 10 open issues; too little visible history this run to judge maintainer responsiveness.
Tags: #assembly #python

💡 Methodological Trend

Two unrelated findings this cycle point the same direction — general-purpose capability bleeding into specialist bioinformatics niches, and known structural tricks turning up in new genomes:
- **General-purpose LLMs doing protein design, no fine-tuning.** A preprint (2025-11-23/24) reports that DeepSeek V3.2, prompted directly, designed viable 4-helix-bundle topologies (40/49 candidates adopted the fold, 36 with pLDDT >70) and improved solubility in 46/50 mutants — without any protein-specific training. No code released, and results are prompt-engineering-level evidence rather than a benchmarked tool, but worth watching as a signal that frontier general LLMs are starting to substitute for purpose-built protein language models on some tasks.
- **A new "jumping element" family, found by looking at an unusual genome.** *Tangerine*, described 2025-11-27, is a Starship-like giant transposable element in lichen-forming fungi (*Xanthoria*) carrying genes horizontally acquired from black yeasts (Chaetothyriales). Starships were previously known mainly from free-living filamentous fungi; finding one in a lichen symbiont extends where this mobile-element class turns up and is a reminder that mobile-element surveys of understudied genomes keep turning up new family members.

**Discovering the unseen: a performance comparison of taxonomic classification methods for unknown DNA barcodes** ([preprint](https://www.biorxiv.org/content/10.1101/2025.10.13.681976), v2 2025-11-24) — benchmark study, not a new tool
Function: Systematically compares existing classifiers (phylogenetic placement methods like EPA-ng vs. composition-based classifiers like SINTAX/RDP-NBC/IDTAXA) on their ability to correctly flag barcodes from taxa absent from the reference database — i.e. on recognising the unknown rather than just classifying the known. Found EPA-ng-style placement better for arthropod COI, composition-based classifiers better for fungal ITS.
