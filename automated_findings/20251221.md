**GUANinE v1.1** (Release Date: 2025-12-10)
Links: [GitHub](https://github.com/ni-lab/guanine) | [Preprint](https://www.biorxiv.org/content/10.64898/2025.12.06.692772)
Function: A benchmark suite (not a model itself) for evaluating genomic sequence-to-function models — this v1.1 release adds new tasks and runs dozens of new genomic language models (DNABERT-2, PhyloGPN, Caduceus, Evo2) against both existing and two new benchmark tasks, directly comparing supervised vs. unsupervised/pretrained approaches.
Use Case: Deciding which genomic language model (if any) is worth adopting for a given sequence-to-function prediction task, rather than taking vendor claims at face value — relevant wherever a pLM-based AMR-from-sequence or functional-annotation pipeline is being evaluated (focus area 2).
Usability Note: EUPL-1.2 license, pip-installable, ReadTheDocs documentation, 82 commits. Small user base (11 stars) — a specialized research benchmark rather than a widely adopted library; too little visible issue history to judge maintainer responsiveness.
Tags: #plm #python #emerging

**Reconstructing local microbial neighborhoods — tool: NeighborFinder** (Release Date: 2025-12-09)
Links: [GitHub](https://github.com/metagenopolis/NeighborFinder) | [CRAN](https://cran.r-project.org/web/packages/NeighborFinder/index.html) | [Preprint](https://www.biorxiv.org/content/10.64898/2025.12.05.692507)
Function: R package that reconstructs the local interaction neighborhood of a chosen bacterial species from microbiome abundance tables, integrating results across several datasets into a shortlist of likely companion/competitor species with a network visualization.
Use Case: Narrowing down which taxa to investigate experimentally when a metagenomic survey flags a species of interest (e.g. a pathogen or AMR-carrying organism) but the full community network is too large to interpret directly.
Usability Note: MIT license, on both CRAN and GitHub, comprehensive README with a 5-step quickstart and vignette, 130 commits. No visible issue history this cycle to judge maintainer responsiveness.
Tags: #metagenomics #r-lang

**CORAL** (Release Date: 2025-12-08) — with companion tool **GAMBA**
Links: [GitHub (CORAL)](https://github.com/EvoDevoGenomics-UB/CORAL) | [GitHub (GAMBA)](https://github.com/nurie05/gamba-tool) | [Preprint](https://www.biorxiv.org/content/10.64898/2025.12.04.692336) | [Zenodo](https://doi.org/10.5281/zenodo.17791010)
Function: Snakemake pipeline that annotates compact, fast-evolving eukaryotic genomes directly from long-read RNA-seq, without gene prediction — each long read captures a full transcript structure, avoiding the short-intergenic-region and overlapping-UTR problems that trip up prediction-based annotators. Demonstrated on the extremely compact, fast-evolving genome of the chordate *Oikopleura dioica*.
Use Case: Annotating any compact or structurally atypical eukaryotic genome (operons, overlapping genes, minimal UTRs) where standard annotation pipelines underperform — the companion GAMBA module (Rust) specifically detects polycistronic transcriptional units in such genomes.
Usability Note: Both MIT (CORAL) and GPL-3.0 (GAMBA) licensed, GitHub Actions CI on both, 154 and 81 commits respectively. GAMBA has minimal community engagement (1 star) so far. Note: the preprint abstract/license banner shows CC-BY-NC 4.0 — that covers the paper text, not the MIT/GPL-3.0-licensed code itself.
Tags: #annotation #assembly #snakemake

**AEGIS** (Release Date: 2025-12-08)
Links: [GitHub](https://github.com/Tomsbiolab/aegis) | [PyPI](https://pypi.org/project/aegis-bio/) | [Docker](https://hub.docker.com/r/tomsbiolab/aegis) | [Preprint](https://www.biorxiv.org/content/10.64898/2025.12.04.692274)
Function: Python toolkit that parses, validates, corrects and standardises genome annotation (GTF/GFF3) files — tidying format inconsistencies, extracting features (CDS, promoters), computing annotation statistics, merging annotations from multiple sources, and running comparative/orthology analyses.
Use Case: Cleaning up and reconciling genome annotations pulled from different sources/pipelines before downstream comparative genomics — a common pain point since GTF/GFF3's flexibility lets different tools produce subtly incompatible files.
Usability Note: GPL-3.0 license, pip/Docker/Singularity install, GitHub Actions CI validating every commit, GitHub Wiki with Jupyter Notebook tutorials, 667 commits. Mature-looking documentation; no visible issue history this cycle to judge maintainer responsiveness for outside users.
Tags: #annotation #comparative-genomics #python

💡 Methodological Trend

- **Defense-system modularity as a discovery strategy, not just a classification scheme.** A preprint this cycle systematically scans bacterial genomes for *non-canonical* combinations of known anti-phage defense domains — rather than only matching whole systems against DefenseFinder's reference models — and found ~2.2x more candidate defense operons than canonical detection alone, with 6 validated as genuinely functional. No code repository was located this cycle (methods-only, not yet a tool), but the approach — treating known functional domains as swappable parts to search combinatorially, rather than as fixed signatures — is a pattern worth watching for defense-system and toxin-antitoxin discovery generally (focus area 10).
- **H5N1 genomic epidemiology keeps getting more granular.** Following last cycle's finding that GenoFlu/Genin2 genotype calls are often phylogenetically incongruent (see [[20261109]] — note: that 2026 report covers a different, later window), this cycle's large-scale H5N1 genome survey (26,930 genomes) identifies distinctive genomic signatures in internal segments (PA, PB2, NP) that distinguish North American lineages and link the two independent 2024-2025 dairy-cattle spillovers (B3.13, D1.1) to the same geographic macro-area — a finer-grained, segment-level complement to genotype-label-based surveillance. See Section B.

ℹ️ Section B: Informational & Proprietary

**Distinctive viral genome signatures linked to repeated mammalian H5N1 spillovers in North America** ([preprint](https://www.biorxiv.org/content/10.64898/2025.12.09.693147), posted 2025-12-09, CC-BY-NC-ND 4.0) — analysis, no software tool released; underlying data/scripts via [Zenodo](https://doi.org/10.5281/zenodo.17669841)
Function: Analyzes 26,930 complete H5N1 genomes to show that internal RNP-complex segments (PA, PB2, NP) carry continent-specific genomic signatures, and that both 2024-2025 US dairy-cattle spillover genotypes (B3.13, D1.1) trace to the same North American macro-region — relevant to H5N1 surveillance interpretation (ECDC/EFSA/NVI priority pathogen).
Tags: #evolution #one-health #surveillance-ready

**Investigating Bacillus anthracis genomic diversity in an anthrax-endemic area of northern Tanzania via culture-free sequencing** ([preprint](https://www.biorxiv.org/content/10.64898/2025.12.04.692280), posted 2025-12-10) — methodology/analysis, no standalone tool
Function: Combines traditional culture-based genomics with a culture-free targeted-capture approach to recover B. anthracis genomes directly from livestock, wildlife and human samples, revealing unexpectedly high strain diversity within single animals and across the landscape, with no clear host-species-specific lineages. Useful proof-of-concept for culture-free genomic surveillance of a zoonotic, One Health-relevant pathogen in settings where culturing is impractical.
Tags: #one-health #evolution

**Mapping the evolutionary path towards multi-drug resistance in the pandemic Escherichia coli ST131 lineage** ([preprint](https://www.biorxiv.org/content/10.64898/2025.12.08.692488), posted 2025-12-10) — population-genomics analysis, no standalone tool
Function: Large-scale genomic reconstruction identifying an intermediary "ST131-B0" progenitor clade between the susceptible ST131-B and resistant ST131-C clades, tied to type I pili switching and chromosomal gain/loss events — argues AMR acquisition alone doesn't explain ST131's epidemiological success.
Tags: #amr #evolution
