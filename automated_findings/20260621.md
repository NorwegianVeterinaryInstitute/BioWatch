🚀 Section A: Command-Line & Secure Analytical Tools (Newest First)

- **CMAPLE 2** (Release Date: 2026-06-16) #phylogenetics #evolution
    - Links: [GitHub](https://github.com/iqtree/cmaple) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.15.732229)
    - Function: Ly-Trong, Martin, Goldman, De Maio, Minh extend CMAPLE (their C++ likelihood-based reimplementation of the MAPLE method for pandemic-scale phylogenetics) with new protein substitution models and usability/API improvements, broadening it from SARS-CoV-2-scale use toward general pathogen genomic epidemiology.
    - Use Case: Building and updating phylogenies of millions of pathogen genomes in tractable time/memory — directly reusable for any large-scale outbreak or endemic-pathogen genomic-surveillance tree (bacterial or viral) that has outgrown standard maximum-likelihood tools.
    - Usability Note: GPL-2.0, comprehensive README (citation, build, usage, contribution), 1,090 commits — mature and actively developed (also integrated into IQ-TREE2). This entry covers the v2 extension, not the original 2024 release, flagged here because the new protein-model support and broadened pathogen-genome scope is what's new this cycle.

- **GT-Trio** (Genotype-based trio-binning) (Release Date: 2026-06-11) #assembly #snakemake
    - Links: [GitHub](https://github.com/theahettasch/GT-Trio) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.08.729486)
    - Function: Hettasch, Gjuvsland, Kent, Grove, Vage (NMBU, Norway) built a Snakemake pipeline that reconstructs parental haplotype sequences from phased parental genotypes (array data imputed to sequence) instead of requiring parental short-read sequencing, then uses this reconstruction for conventional trio-binning assembly.
    - Use Case: Haplotype-resolved genome assembly for breeding populations where genotype (SNP-chip) data already exists for the parents but short-read sequencing does not — demonstrated on three Norwegian Red cattle trios with phasing accuracy comparable to true trio-binning, removing a cost barrier to haplotype-resolved assembly for livestock and other genotyped breeding populations.
    - Usability Note: MIT license, README with install/usage for local and cluster runs, 41 commits, 0 stars — brand-new academic release from a livestock-genetics group, too young to assess issue-responsiveness. Needs Conda + Snakemake, plus BCFtools/SAMtools/Yak/Hifiasm/RagTag.

- **Apollo 3** (Release Date: 2026-06-11) #annotation #comparative-genomics
    - Links: [GitHub](https://github.com/GMOD/Apollo3) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.08.730970)
    - Function: Stevens, Beraldi, Haese-Hill, Diesh, Berriman, Holmes et al. (the GMOD/Apollo team) released Apollo 3, a from-scratch rewrite of the manual genome-annotation editor as a native JBrowse 2 plugin, adding ontology-aware feature typing and multi-species project support.
    - Use Case: Collaborative, browser-based manual curation and correction of gene models across one or many genomes at once — directly useful for finishing or QC'ing ab initio annotation calls (in the vein of Tiberius/OrionGeno from earlier cycles) on any newly assembled pathogen, host or vector genome.
    - Usability Note: Apache-2.0, README present, 845 commits, 18 stars, 58 open issues and 7 open PRs — a mature GMOD-ecosystem project with visible, active issue engagement.

- **RERconverge** (performance/analysis update) (Release Date: 2026-06-10) #evolution #comparative-genomics
    - Links: [GitHub](https://github.com/nclark-lab/RERconverge) | [bioRxiv preprint](https://doi.org/10.64898/2026.06.06.730612)
    - Function: Hoffmann, Kopania, Tene, Kowalczyk, Redlich, Pfenning, Meyer, Chikina, Clark overhaul RERconverge (their R package testing association between a gene's relative evolutionary rate and a convergent phenotype across a phylogeny), cutting runtime by up to 28.6x and adding two new outlier-control methods to the phenotype-association test.
    - Use Case: Genome-wide scans for genes whose evolutionary rate tracks a convergently-evolved trait across a species tree — e.g. repeated evolution of a resistance or life-history trait — now practical at much larger tree/gene-set scales than before.
    - Usability Note: GPL-3.0, comprehensive README/manual/wiki, 590 commits, 71 stars — mature, well-maintained package from an established comparative-genomics lab. This is a performance/analysis-function update, not a first release, flagged because the speedup and new outlier controls are what's new this cycle.
