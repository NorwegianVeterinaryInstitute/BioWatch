- **PanBART** (Release Date: 2026-04-30) #amr #comparative-genomics #one-health
    - Links: [GitHub](https://github.com/samhorsfield96/panBART) | [bioRxiv preprint](https://doi.org/10.64898/2026.04.28.721069) | [Pretrained models (Zenodo)](https://zenodo.org/records/19815224)
    - Function: Horsfield, Wiatrak, McInerney, Bentley, Colijn, Lees et al. (Wellcome Sanger/Lees lab) trained PanBART, a long-context encoder-decoder transformer (LED architecture) on the gene content and gene order of two major bacterial pathogens (*E. coli*, *S. pneumoniae*), learning population-structure representations directly from pangenome data in an unsupervised way.
    - Use Case: Assigns genomes to biologically meaningful lineages, flags emergent lineages, and — most relevant here — predicts which genomic backgrounds are likely to acquire antibiotic-resistance genes *before* a horizontal-transfer event occurs, plus co-selection analysis for gene pairs likely to be acquired together; a forward-looking complement to retrospective AMR-lineage surveillance tools from the same lab ecosystem (Kleborate, PopPUNK).
    - Usability Note: CC-BY-4.0 (a content license, somewhat unusual for code but permissive), README and LICENCE present, 189 commits, 9 stars, pretrained *E. coli*/*S. pneumoniae* models released on Zenodo (v0.1.0) — from an established bacterial-genomic-epidemiology lab with a strong maintenance track record, though this specific tool is new and too young to assess issue-responsiveness individually.

- **AssayBLAST v2** (Release Date: 2026-04-29) #python #one-health
    - Links: [GitHub](https://github.com/rnajena/AssayBLAST) | [bioRxiv preprint](https://doi.org/10.64898/2026.04.27.721032) | [PyPI](https://pypi.org/project/assay-blast/)
    - Function: Eulenfeld, Collatz, Braun, Ehricht et al. (Leibniz-IPHT/InfectoGnostics) released a major update to AssayBLAST, their in silico PCR primer/probe evaluation tool, which uses BLAST hits and mismatch counts to simulate oligo-target hybridisation outcomes and now supports multi-genome, multi-parameter assay searches in a single run.
    - Use Case: Rational design and validation of multiplex PCR/microarray assays (primers, probes) against a genome database before bench work — validated to 97.5% accuracy against experimental *S. aureus* microarray data — directly reusable for designing or auditing AMR-gene or pathogen-typing probe panels across multiple target genomes at once.
    - Usability Note: MIT license, comprehensive README, 110 commits, 7 stars, pip/conda installable alongside a BLAST+ installation — a mature, actively maintained diagnostic-tooling project from an established assay-design lab (Ehricht: CarbaDetect, INTER-ARRAY). This is a major version update (v2), not a first release, flagged here because the new multi-genome/multi-parameter capability is what's new this cycle.

- **OrionGeno** (Release Date: 2026-04-29) #annotation #python
    - Links: [GitHub](https://github.com/BGIResearch/OrionGeno) | [bioRxiv preprint](https://doi.org/10.64898/2026.04.26.720859) | [PyPI](https://pypi.org/project/oriongeno/)
    - Function: Liu, Cai, Wang et al. (BGI Research) built OrionGeno, a multispecies phylogeny-aware deep-learning framework for end-to-end eukaryotic genome annotation, jointly predicting exon-intron structure, UTRs and repeats directly from a genome FASTA plus a species name, reporting a 37.2% relative improvement in protein-level F1 over the best existing method across vertebrates, invertebrates, plants and fungi.
    - Use Case: Ab initio annotation of newly assembled eukaryotic genomes (including non-model/difficult genomes) without extrinsic evidence — released the same week as Tiberius (below), giving two independent deep-learning ab initio annotators to cross-check against for any new eukaryotic pathogen, host or vector genome.
    - Usability Note: **Academic/non-commercial license only** (not GPL/MIT) — usable for NVI research but a caveat for any downstream commercial or diagnostic-service use; README and LICENSE present, 17 commits, 31 stars, pip-installable, Docker support — too new to assess issue-responsiveness or ongoing maintenance.

- **Tiberius** (Release Date: 2026-04-28) #annotation #python #docker
    - Links: [GitHub](https://github.com/Gaius-Augustus/Tiberius) | [bioRxiv preprint](https://doi.org/10.64898/2026.04.24.720536) | [Web server](https://bioinf.uni-greifswald.de/tiberius/)
    - Function: Gabriel, Brůna, Stanke, Hoff et al. (University of Greifswald — the AUGUSTUS/BRAKER team) report multi-clade validation and extension of Tiberius, their deep-learning ab initio gene predictor that end-to-end integrates a CNN, a bidirectional LSTM and a differentiable HMM layer, matching evidence-based annotators' accuracy from genome sequence alone across mammals, insects, plants, fungi and algae.
    - Use Case: Fast, extrinsic-evidence-free eukaryotic gene annotation across a wide taxonomic range — directly applicable to any newly assembled host, vector or parasite eukaryotic genome lacking RNA-seq/protein evidence, runnable locally (Docker/Singularity) or via the project's own web server for labs without GPU access.
    - Usability Note: MIT license, README and LICENSE present, 348 commits, 144 stars — a mature, actively developed tool from an established gene-annotation lab. This entry describes a multi-clade validation/capability extension, not a first release (the tool already carries substantial commit history), flagged here because the new multi-clade accuracy evidence is what's new this cycle.
