    - Usability Note: MIT license, 21 commits, comprehensive README with worked examples and 18 passing tests, full experiment outputs archived on Zenodo for reproducibility — but brand new (2 stars, 0 forks, no issue history yet), a library (Cargo dependency) rather than a CLI, and the benchmark claims are from the authors' own paper, not yet independently reproduced. - **Chromosome-scale nuclear and mitochondrial genome assemblies reveal extreme genome compartmentalization in the hazelnut pathogen *Anisogramma anomala*** ([bioRxiv preprint](https://www.biorxiv.org/content/10.64898/2026.10.20.760510), posted 2026-10-26) — reference genome + comparative-genomics finding, no software release #assembly #evolution

- **Systematic genome analysis enables long-overdue taxonomic reorganization of genus *Orthoflavivirus*; potential assignment of over 50 new species** ([bioRxiv preprint](https://www.biorxiv.org/content/10.64898/2026.10.21.760428), posted 2026-10-26) — taxonomy proposal, no software release #evolution #one-health
